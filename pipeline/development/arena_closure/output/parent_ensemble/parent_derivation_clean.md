# Re-derived parent set from 4,150 raw labels (deliberation-rich, PM-purpose)

Single Opus 4.7 call. Input: 4,150 raw parent labels from the 50-rep ensemble. Output: a canonical parent set + per-parent rationale + per-borderline-decision deliberation entries. Skips the original consolidation step that produced the 126 canonical classes.

**Cost:** $2.15, 418s wall.
**Tokens:** 274,392 in / 31,297 out (stop=end_turn).

**Parents derived: 91**
**Deliberation entries: 50**

## Rationale

The 4,150 raw labels show extremely high redundancy: roughly 30-40 mechanism families recur in nearly every rep (data, measurement, model, regulatory framework, capital cost, etc.) and an additional 50-60 narrower-but-real mechanisms appear in 30-70% of reps. I synthesised 91 parents calibrated to a PM diagnostic vocabulary — granular enough that distinct mechanisms (e.g. p33 price-signal distortion vs p34 absent value-capture mechanism; p39 regulatory absence vs p40 misfit; p29 heterogeneity vs p30 correlation) remain distinguishable, but consolidated where reps split mechanisms PMs treat together (e.g. p45 merges multi-party coordination with responsibility gaps; p13 combines IBR dynamics with system-strength loss).

Key boundary principles: (1) Mechanism-class not technology — storage, hydrogen, solar all collapse into the relevant mechanism parent (per constraint 1). (2) Tightness over breadth — split when 'or' would be needed (p61 behavioural vs p62 rebound; p29 invisibility vs p30 correlation). (3) Recurrence calibration — high-recurrence labels (run_18:p01, run_05:p01, run_43:p01 for missing data) become foundational parents; low-recurrence but mechanistically distinct families (p78 hard-to-abate, p90 equity, p85 curtailment) retained when they name patterns PMs would otherwise lack vocabulary for.

Notable consolidations: forecast accuracy + model error → p04 (PMs assess them together); workforce skills + key-person → kept separate (p51/p52) because remediation differs; legacy infrastructure (p66) + architectural rigidity (p67) + SPOF (p68) kept separate because each names a distinct evolutionary or operational property.

## Notes

Structural observations: (1) Recurrence is heavily bimodal — ~35 mechanism families appear in 90%+ of reps, then a long tail of narrow mechanisms appear in 5-30% of reps. The variation suggests no consensus on optimal parent count, validating PM-purpose calibration as the deciding criterion.
